# Yuku

Yuku is a minimal Android browser built on WebView with a custom Jetpack Compose interface. Layout logic is borrowed from some another long abandoned browser, with some visual and behavior improvements and QOL features added.

## Main features

- Tabbed browsing with a dedicated private browsing space
- Omnibox for URLs and searches, with recents and most used sites suggestions
- Vertical tab switcher with swipe gestures
- Bookmarks, searchable history, downloads
- Reader mode, dark mode for sites
- Configurable ad, tracker, and cookie-banner blocking
- Password, address, and payment-card autofill protected by Android Keystore
- Support for links opened from other apps through a Custom Tabs provider

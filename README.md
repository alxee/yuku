# Yuku

Yuku is a minimal Android browser built on WebView with a custom Jetpack Compose interface. Its layout keeps the page central while putting commonly used browsing tools within quick reach.

The bottom toolbar opens the tab switcher, starts a new tab, and reveals the browser menu. From the menu, users can navigate, reload, copy an address, search within a page, switch to desktop mode, adjust text size, use reader mode, manage downloads, and open site-specific settings.

## Main features

- Tabbed browsing with a dedicated private browsing space
- Omnibox for URLs and searches, with recent-history suggestions
- Tab switcher with swipe-to-close and close-all actions
- Back, forward, reload, address copying, and find in page
- Bookmarks, searchable history, and downloads
- Reader mode, page dark mode, desktop mode, and text-size controls
- Configurable ad, tracker, and cookie-banner blocking
- Per-site controls for blocking, appearance, text size, and permissions
- Password, address, and payment-card autofill protected by Android Keystore
- File uploads, download confirmations, fullscreen video, dialogs, HTTP authentication, and certificate warnings
- Support for links opened from other apps through a Custom Tabs provider
- System default-browser and standard Android VIEW intent support
